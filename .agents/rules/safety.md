# Safety & Operational Rules

These rules are mandatory and take precedence over all other instructions.

1. **No commands without explicit permission**
   - Never execute any shell or terminal command before asking the user and receiving explicit permission for that exact command.
   - Before asking, state the exact command you intend to run and why it is needed.

2. **No `git` commands**
   - Never execute any `git` command under any circumstances (including read-only commands such as `git status`, `git diff`, or `git log`).

3. **Stay strictly inside this directory**
   - Never read, inspect, list, search, or modify any file or directory outside this project directory.
   - All actions must remain strictly scoped to this workspace root and its subdirectories.

4. **No file changes without explicit permission**
   - Never create, modify, or delete any file without first stating the exact file(s) and intended change(s) and receiving explicit permission from the user.
